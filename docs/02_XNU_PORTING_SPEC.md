# XNU Kernel Porting & Platform Expert Specification

## 1. Apple XNU Open-Source Architecture
The open-source release of XNU (`apple-oss-distributions/xnu`) combines:
* **Mach 3.0:** Microkernel layer managing tasks, threads, virtual memory (`vm_map`), and IPC (Mach messages/ports).
* **BSD (FreeBSD derived):** POSIX subsystem, process management, signals, socket networking, and VFS.
* **IOKit:** Object-oriented C++ driver framework based on restricted C++ (no templates, no multiple inheritance).
* **osfmk / pexpert:** Platform Expert subsystem responsible for hardware abstraction, early boot, and board discovery.

---

## 2. Platform Expert (`pexpert`) for MediaTek MT6769H

In XNU, the `pexpert` interface initializes the target CPU board before Mach and BSD take over.

### Essential Subsystems Required for `pe_fire.c`:
1. **Serial Console (`pe_serial`):**
   * Maps MediaTek MTK UART registers (`0x11002000`).
   * Implements basic polling `putc()` and `getc()` routines for kernel printk / panic logs.
2. **Interrupt Controller Driver:**
   * Replaces Apple AIC mapping with ARM Generic Interrupt Controller (GICv2/v3).
   * Maps GIC Distributor (`GICD`) and GIC CPU Interface (`GICC`).
3. **Timer Driver:**
   * Configures ARM Generic Timer (`CNTP_TVAL_EL0`, `CNTP_CTL_EL0`) to drive Mach ticks and scheduler preemption.

## 3. The Device Tree Bridge (FDT to Apple DeviceTree)

* **Linux on Android:** Bootloader loads Flattened Device Tree Blob (`.dtb`).
* **XNU Requirement:** Expects an Apple-proprietary packed binary Device Tree generated by `iBoot`.

```mermaid
graph LR
    A["MediaTek Device Tree (.dtb)"] --> B["fdt2adt Translator Tool"]
    B --> C["Apple Device Tree Structure (ADT)"]
    C --> D["XNU boot_args & PE_state"]
```

### Required Node Translations:
* `/cpus`: ARM Core topologies and MPIDR mapping.
* `/memory`: Physical RAM base (`0x40000000`) and size.
* `/soc/serial`: UART base and IRQ line.
* `/chosen`: Kernel command-line arguments (`boot-args`, e.g., `-v debug=0x14e serial=2 amfi_get_out_of_my_way=1`).
